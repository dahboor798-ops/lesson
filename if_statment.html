الجمل الشرطية في لغة بايثون

بيئة تعليمية تفاعلية — تعلّم بالممارسة والتجربة والاكتشاف

أهلًا بك 👋

في هذه الصفحة ستتعلم الجمل الشرطية في لغة بايثون — أي كيف تجعل البرنامج يتخذ قرارًا بناءً على شرط معين.

هذه الصفحة ليست اختبارًا، وليست امتحانًا. ستجد فيها:

  • أمثلة حياتية قريبة منك.
  • أنشطة تتوقع فيها ناتج الشيفرة قبل تشغيلها.
  • أنشطة تكتشف فيها الأخطاء وتصلحها.
  • محاكيات تجرّب فيها تغيير قيم المتغيرات ومشاهدة النتيجة.
  • تلميحات متدرجة تُظهر لك الحل عند الحاجة.

تذكّر: الخطأ جزء من التعلم، وليس نهاية النشاط. جرّب، وأعد المحاولة، واكتشف القاعدة بنفسك.

تقدّمك الحالي

لم تبدأ أي نشاط بعد.

كيف تستخدم الصفحة؟

  1. ابدأ من وحدة «مفهوم القرار» ثم تابع بالترتيب.
  2. في كل نشاط، جرّب المحاولة الأولى بنفسك.
  3. إذا احتجت مساعدة، اضغط زر «تلميح» — ستظهر لك تلميحات متدرجة.
  4. عند الانتهاء من نشاط، ستُحفظ تلقائيًا في تقدّمك على جهازك.

١. مفهوم اتخاذ القرار في البرمجة

البرنامج لا ينفذ الأوامر كلها دائمًا؛ أحيانًا يحتاج إلى قرار: «إن تحقق شيء مُعيّن، نفّذ أمرًا، وإلا نفّذ غيره». هذا هو معنى الجملة الشرطية.

نشاط ١.١ — موقف حياتي اكتشاف

لديك مكيّف منزلي يعمل تلقائيًا: إذا كانت درجة الحرارة أعلى من ٢٨ يعمل المكيف ويُظهر «تشغيل التبريد»، وإلا يُظهر «الجو معتدل».

غيّر درجة الحرارة وشاهد القرار:

temp = 32
if temp > 28:
    print("تشغيل التبريد")
else:
    print("الجو معتدل")

نشاط ١.٢ — قارن بين مثالين اكتشاف

اقرأ المثالين ثم أجب: أيّهما سيُطبع فيه «مسموح»؟

# المثال أ
age = 15
if age >= 18:
    print("مسموح")
# المثال ب
age = 20
if age >= 18:
    print("مسموح")

٢. الجملة الشرطية if

صيغة الجملة الشرطية البسيطة: if condition: ثم كتلة بادئة. إذا كانت قيمة الشرط True تُنفّذ الكتلة، وإن كانت False تُتجاهَل.

if condition:
    # هذا الكود ينفذ إذا تحقق الشرط فقط
    print("...")

نشاط ٢.١ — توقّع الناتج تنبؤ

اقرأ الشيفرة التالية ثم توقع الناتج.

temperature = 35
if temperature > 30:
    print("الجو حار")

نشاط ٢.٢ — أكمل الشيفرة إكمال

الهدف: طباعة «مسموح بالدخول» إذا كان عمر الطالب ١٨ أو أكثر. اختر الشرط الصحيح.

age = 18
if :
    print("مسموح بالدخول")

نشاط ٢.٣ — المسافات البادئة اكتشاف

في بايثون، الكود التابع للشرط يجب أن يكون مُزاحًا للداخل (عادة ٤ مسافات). ماذا يحدث لو نسينا الإزاحة؟

temp = 35
if temp > 30:
print("حار")

٣. الجملة if … else

إذا أردنا أن ينفذ البرنامج قرارًا واحدًا عند تحقق الشرط وقرارًا آخر عند عدم تحققه، نستخدم else.

if condition:
    # يُنفذ عند True
    ...
else:
    # يُنفذ عند False
    ...

نشاط ٣.١ — توقع الناتج تنبؤ

grade = 45
if grade >= 50:
    print("ناجح")
else:
    print("راسب")

نشاط ٣.٢ — أكمل فرع else إكمال

الهدف: طباعة «كبير» إذا كان العمر ١٨ فأكثر، و«صغير» لغير ذلك. اختر ما يكمل الشيفرة.

age = 15
if age >= 18:
    print("كبير")

    print("صغير")

نشاط ٣.٣ — مطابقة الناتج مع قيمة المتغير مطابقة

لدينا الشيفرة التالية. اضغط على قيمة، ثم اضغط الناتج المناسب لها.

score = ?
if score >= 60:
    print("نجاح")
else:
    print("رسوب")
score = 75
score = 60
score = 30
يُطبع «نجاح»
يُطبع «رسوب»
يُطبع «نجاح»

٤. الجملة elif

عندما يكون لدينا أكثر من احتمال، نستخدم elif (اختصار else if). يُفحص كل شرط بالترتيب، وأول شرط يتحقق يُنفّذ كتلته ثم يتوقف.

if condition1:
    # المسار الأول
elif condition2:
    # المسار الثاني
else:
    # المسار الافتراضي

نشاط ٤.١ — توقّع الناتج تنبؤ

score = 78
if score >= 90:
    print("ممتاز")
elif score >= 80:
    print("جيد جدًا")
elif score >= 70:
    print("جيد")
else:
    print("يحتاج مراجعة")

نشاط ٤.٢ — ترتيب الشروط مهم! اكتشاف

انظر إلى الشيفرة التالية. ماذا سيُطبع إذا كانت score = 95؟

score = 95
if score >= 70:
    print("جيد")
elif score >= 90:
    print("ممتاز")
else:
    print("يحتاج مراجعة")

نشاط ٤.٣ — أكمل سلسلة elif إكمال

الهدف: طباعة «موجب» إذا كان العدد أكبر من صفر، و«سالب» إذا كان أصغر من صفر، و«صفر» إذا كان يساوي صفرًا. ما الشرط الصحيح للفرع الثاني؟

n = -3
if n > 0:
    print("موجب")
elif :
    print("سالب")
else:
    print("صفر")

٥. معاملات المقارنة

معامل المقارنة يُرجع قيمة منطقية: إمّا True أو False. تذكّر الفرق المهم: = للإسناد، و== للمقارنة.

==   يساوي
!=   لا يساوي
>    أكبر من
<    أصغر من
>=   أكبر من أو يساوي
<=   أصغر من أو يساوي

نشاط ٥.١ — طابق المعامل بمعناه مطابقة

==
!=
>=
<
أكبر من أو يساوي
يساوي
أصغر من
لا يساوي

نشاط ٥.٢ — اختر المعامل المناسب إكمال

الهدف: طباعة «درجة ناجحة» إذا كانت الدرجة بين ٥٠ و١٠٠ (أي أكبر من أو تساوي ٥٠).

grade = 72
if grade  50:
    print("درجة ناجحة")

نشاط ٥.٣ — الفرق بين = و == تصنيف

صنّف الجمل التالية: هل تستخدم = (إسناد) أم == (مقارنة)؟

1. x ___ 5 — نريد إعطاء x القيمة 5  
2. if x ___ 5: — نريد التحقق هل x يساوي 5  
3. name ___ "Ali" — نريد إعطاء name القيمة "Ali"  

٦. القيم المنطقية والشروط المركبة

القيمة True تعني «صحيح»، وFalse تعني «خطأ». يمكن دمج شرطين باستخدام and (يجب تحقق الاثنين) وor (يكفي تحقق أحدهما) وnot (عكس).

and : كلا الشرطين صحيح
or  : أحدهما على الأقل صحيح
not : يعكس القيمة المنطقية

نشاط ٦.١ — قيّم التعبيرات تنبؤ

اختر القيمة المنطقية الصحيحة لكل تعبير.

10 > 5
3 == 4
(5 > 2) and (3 < 1)
(5 > 2) or (3 < 1)
not (2 == 2)

نشاط ٦.٢ — شرط مركب واقعي إكمال

الهدف: طباعة «مسموح بالسفر» إذا كان عمر الشخص ١٨ فأكثر وكان يملك جواز سفر. اختر الشرط المناسب.

age = 20
has_passport = True
if :
    print("مسموح بالسفر")
else:
    print("غير مسموح")

٧. اكتشاف الأخطاء وتصحيحها

كل مبرمج يخطئ. المهم أن يكتشف الخطأ ويفهم سببه. في الأنشطة التالية ستجد أخطاء شائعة.

نشاط ٧.١ — خطأ شائع: = بدل == تصحيح

الشيفرة التالية فيها خطأ. اضغط على السطر الذي يحتوي الخطأ.

x = 10
if x = 5:
    print("خمسة")
else:
    print("ليس خمسة")

نشاط ٧.٢ — خطأ شائع: النقطتان تصحيح

في بايثون، بعد if والشرط يجب وضع :. اضغط على السطر الذي ينقصه النقطتان.

grade = 80
if grade >= 50
    print("ناجح")
else:
    print("راسب")

نشاط ٧.٣ — خطأ في الإزاحة تصحيح

الشيفرة التالية فيها خطأ في الإزاحة. أين يوجد؟

temp = 20
if temp > 30:
print("حار")
else:
    print("معتدل")

نشاط ٧.٤ — ترتيب elif خاطئ تصحيح

الشيفرة التالية منطقية لكنها لا تعطي النتائج المتوقعة لدرجة 95. ما المشكلة؟

score = 95
if score >= 50:
    print("ناجح")
elif score >= 90:
    print("ممتاز")

٨. المحاكي البرمجي

هذا محاكٍ تعليمي مصغّر. غيّر قيم المتغيرات واضغط «تشغيل» لمشاهدة تسلسل التنفيذ خطوة بخطوة. ملاحظة: هذا المحاكي ينفذ سيناريوهات مُعدّة مسبقًا، وليس بيئة بايثون حقيقية — يُستخدم للفهم فقط.

محاكي ٨.١ — تحديد النجاح محاكاة

grade = 75
if grade >= 50:
    print("ناجح")
else:
    print("راسب")

محاكي ٨.٢ — حالة الطقس محاكاة

temp = 30
if temp > 35:
    print("حار جدًا")
elif temp > 25:
    print("دافئ")
elif temp > 15:
    print("معتدل")
else:
    print("بارد")

محاكي ٨.٣ — إشارة العدد محاكاة

n = -5
if n > 0:
    print("موجب")
elif n < 0:
    print("سالب")
else:
    print("صفر")

محاكي ٨.٤ — الخصم على المشتريات محاكاة

total = 150
if total >= 200:
    discount = 20
elif total >= 100:
    discount = 10
else:
    discount = 0
final = total - (total * discount / 100)
print("الخصم:", discount, "%")
print("المبلغ النهائي:", final)

٩. الربط بين الحياة والبرمجة

في كل موقف، اختر الشيفرة الصحيحة التي تُعبّر عنه.

نشاط ٩.١ — خصم المتجر ربط

الموقف: إذا تجاوزت قيمة المشتريات ٢٠٠ ريال، يحصل المشتري على خصم ١٠٪. ما الشيفرة الصحيحة؟

نشاط ٩.٢ — العدد الزوجي ربط

الموقف: نريد تحديد ما إذا كان العدد زوجيًا (يقبل القسمة على ٢ دون باقٍ). ما الشرط الصحيح؟

نشاط ٩.٣ — فئة عمرية ربط

الموقف: إذا كان العمر أقل من ١٣ فهو «طفل»، وإذا كان بين ١٣ و١٧ فهو «مراهق»، وإلا فهو «بالغ». أي الشيفرات صحيحة؟

١٠. التحدي الإبداعي

الآن دورك! ابتكر برنامجًا صغيرًا يستخدم الجمل الشرطية لحل مشكلة من اختيارك. اكتب فكرتك هنا.

أفكار إرشادية

  • برنامج يقيّم علامة الطالب ويعطي تقديرًا.
  • برنامج يحدد سعر تذكرة بناءً على العمر.
  • برنامج يحدد نوع اليوم (دراسة / عطلة).
  • برنامج يحدد ما إذا كان العدد موجبًا أو سالبًا أو صفرًا.
  • برنامج يحدد أهلية التصويت بناءً على العمر.

تقدمك

اقتراحات لمزيد من التدريب

  • جرّب كتابة برنامج يحسب الضريبة بناءً على قيمة الشراء.
  • جرّب برنامجًا يحوّل الدرجة الرقمية إلى تقدير (A، B، C...).
  • جرّب برنامجًا يقارن بين رقمين ويطبع الأكبر.
  • جرّب برنامجًا يحدد ما إذا كانت السنة كبيسة أم لا (تحتاج %).
  • جرّب بناء لعبة تخمين رقم بسيطة مع تلميحات «أعلى/أدنى».
